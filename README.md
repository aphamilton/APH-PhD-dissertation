# AH_PhD_dissertation
Sharing code created for my dissertation research.

The R code (SZ_ASD_L1_L2_analysis) is the main code produced for my dissertation, which does data wrangling and data analysis. I have posted a few versions from various stages. It requires several data files to run. The version from 2026_04_21 is the version used to produce the results for the first associated research paper.

The PsychoPy/PsychoJS code (ending in .psyexp) is to run the non-linguistic tasks participants complete on Pavlovia. Note that the Digit-Symbol Coding task (first of three tasks) was adapted from a version by another researcher that they kindly shared for re-use.

The script called LDT_Generator was used to create matching English and French stimuli for a lexical decision task (LDT) for my EEG experiment.
