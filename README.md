# AH_PhD_dissertation
Sharing code created for my dissertation research. The R code is for data cleaning and data analysis. The PsychoPy/PsychoJS code is to run the non-linguistic tasks participants complete on Pavlovia. Note that the Digit-Symbol Coding task (first of three tasks) in the PsychoPy file was adapted from a version by another researcher that they kindly shared for re-use.
